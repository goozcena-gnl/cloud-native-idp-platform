# Contributing

This is a personal portfolio project.

## Development workflow

1. Create a branch.
2. Make a small, focused change.
3. Validate locally.
4. Update documentation.
5. Commit with a clear message.
6. Open a pull request when GitHub remote is configured.

## Commit style

Use clear, descriptive commit messages, for example:

- chore: initialize repository structure
- docs: add project charter
- feat: add argocd bootstrap manifests
- security: add kyverno baseline policies
